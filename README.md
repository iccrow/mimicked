# Mimicked

Mimicked is a horror-themed Minecraft mod that adds an unsettling atmospheric element by recording and playing back player voices through various entities in the game. It uses the Simple Voice Chat API to capture audio and applies various sound effects to create a haunting experience.

## Overview

- **Voice Mimicking:** Occasionally records player speech and plays it back later from nearby entities.
- **Dynamic Sound Effects:** Applies various audio distortions (reversal, pitch shift, stutter, radio interference, etc.) to mimic clips.
- **Overdrive System:** Increases the frequency and intensity of mimicking when near specific "overdrive" entities.
- **Highly Configurable:** Control recording chances, playback sparsity, clip storage, and specific sound effect parameters.

## Requirements

- **Minecraft:** 1.21.1
- **Minecraft NeoForge:** 21.1.235 (built and tested on)
- **Dependency:** [Simple Voice Chat](https://modrinth.com/mod/simple-voice-chat) (required at runtime)
- **Java:** 21

## Configuration

The mod generates two main configuration files in the `run/config` directory:

### `mimicked-common.toml`
Controls the core behavior of the mod:
- **Thresholds:** Audio amplitude and RMS thresholds for voice detection.
- **Recording:** Chance to record and maximum clip length/storage.
- **Playback:** Average sparsity of mimic events and deletion chances.
- **Hosts:** Whitelisting entities that can mimic players.
- **Overdrive:** Entities that trigger "overdrive" mode for more frequent mimicking.

### `mimicked-sfx.toml`
Controls the sound effects applied to mimicry:
- **General:** Chances for SFX and overlapping effects.
- **Overdrive:** SFX chances during overdrive events.
- **Effect Specifics:** Individual settings for Pitch Shift, Stutter, Reversal, Radio Interference, etc.

## Project Structure

- `src/main/java`: Source code for the mod.
  - `com.crow.mimicked`: Main mod class and networking.
  - `com.crow.mimicked.audio`: Audio management and processing.
  - `com.crow.mimicked.audio.fx`: Sound effect implementations and configuration.
- `src/main/resources`: Assets and metadata.
  - `META-INF/mods.toml`: Forge mod metadata.
- `src/generated`: Resources generated by data generators.
